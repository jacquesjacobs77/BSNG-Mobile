# BSNG Research Studio v0.1 — architecture

- This is an Android-first, responsive Expo / React Native **research interface**.
- The legacy BSNG Tkinter desktop program remains untouched. The tablet design notes inform styling.
- JASTUDIO AI Brain v0.5 is an architectural reference. It is NOT connected to the mobile app.
- The 15-million-base-pair batch target, genome reference loading, checkpoints, remote AI, permanent notes and results are planned backend work, not implemented.
- The sole local scientific calculation is deterministic GC composition in short DNA strings and 15-bp sliding windows. This does not model or prove nanite binding.
- The nanite workspace records **conceptual categories only**. No real nanites are synthesized or validated.
- A user-provided GRCh38.p14 manifest refers to a Windows-only FASTA path; no reference file is bundled.
- Do not commit keys, confidential human genomes or other restricted data to this public repository.

## Planned future services (not implemented)
- Experiment and provenance API (version, input manifest, parameters, datasets, checkpoints).
- Chunked genome jobs with idempotency, boundaries, restart checkpoints and immutable results.
- Authenticated JASTUDIO AI model routing with isolated BSNG research storage.
- Evidence retrieval, hypothesis logging, independent validation and report export.

This repository begins as an app shell, not a claim of biological feasibility.
